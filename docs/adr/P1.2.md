## Gate

All items must be completed before the phase can be closed.

- [ ] Identical states produce identical fingerprints across runs and machines with the same Git version

  Evidence:

  - Partial. BuildAsync_ProducesSameFingerprintsForSameRepositoryState
    compares two builds in one temporary repository. The golden tests
    HsGolden001_ProducesIndependentExpectedFingerprints and
    WorktreeGolden001_ProducesIndependentExpectedFingerprints check the same
    expected values on windows-latest and ubuntu-24.04 (CI Run 42514683492).
    That run reports Git `2.56.0.windows.4` and `2.56.0`, so it is not a
    controlled comparison of machines with the same Git version. See
    P1.2-CR-004.

  Evidence:

    launch in Core and Contracts only; it does not cover Cli or Git output
    parsing.

- [x] The serialized form round-trips and rejects unknown record types

  Evidence:

### P1.2-CR-003

- Type: GATE
- Status: OPEN

Discovered:

- 2026-10-25

Description:

Proposed gate addendum (MO3 of the P1.2 micro-plan): an observed repository
state such as a vanished, locked, or unreadable file must not end in an
unhandled exception from `BuildAsync`. `BuildAsync` returns a failure result
with a diagnostic and no Snapshot. Only `OperationCanceledException` caused
by the caller's cancellation token may leave `BuildAsync`. Proven violation
on `main`: F10 (see In Progress).

Impact:

- Gate

Result:

Pending. Not part of the ratified gate until accepted.

### P1.2-CR-004

- Type: PLAN
- Status: OPEN

Discovered:

- 2026-11-12

Description:

Found by the independent audit of pull request #20. The gate criterion
"identical fingerprints across runs and machines with the same Git version"
was ticked on evidence that does not control the Git version: the cited CI
run used `2.56.0.windows.4` on Windows and `2.56.0` on Ubuntu. The golden
tests support portability of the fixtures; they do not show the criterion as
worded. It stays unchecked until evidence for the criterion as worded is
recorded. The maintainer may define what "the same Git version" means across
platforms; such a definition sets how evidence is judged and does not
replace the evidence.

Impact:

- Gate

Result:

Pending.
