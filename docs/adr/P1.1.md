## Purpose

A reliable, isolated way to ask Git questions, on Windows and Linux, without a
shell and without inheriting the caller's Git context.

## Notes

The evidence for "read-only invocations avoid touching the index" proves that
`GIT_OPTIONAL_LOCKS=0` is set for read-only commands. It does not observe the
index file itself.

I4 has one documented exception (choosing Git before Git can be asked); it is
defined in docs/architecture.md and not repeated here.
