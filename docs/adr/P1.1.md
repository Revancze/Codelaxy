## Purpose

A reliable, isolated way to ask Git questions, on Windows and Linux, without a
shell and without inheriting the caller's Git context.

## Gate

All items must be completed before the phase can be closed.

- [ ] Every test that requires repository state creates its own temporary repository; no test reads or mutates repository state of the Codelaxy development repository

  Evidence:

  - None. No automated check guards this. See P1.1-CR-001.

- [ ] The poisoned-environment test fails if isolation is removed

  Evidence:

  - None recorded. The poisoned-environment tests exist
    (RunAsync_IgnoresInheritedGitDir and siblings), but no run with isolation
    removed is recorded in this repository. See P1.1-CR-001.

- [x] No code path constructs a shell command line

  Evidence:

  - ProductionCode_DoesNotUseShellIntermediary
  - ProductionCode_DoesNotEnableShellExecution
  - ProductionCode_DoesNotUseStringArguments
  - CI Run 42514683492
  - Limit: the three tests are static checks of the `*.cs` files under
    `src`, outside `bin` and `obj`, for fixed text patterns. They reject
    known shell names as string literals, `UseShellExecute = true`, and
    assignment to `Arguments`. They do not prove the absence of every
    possible code path.

- [x] A missing Git executable produces a diagnostic, not an exception and not an evidence state

  Evidence:

  - RunAsync_ReturnsLaunchFailureWhenGitCannotBeStarted
  - RunAsync_ReturnsLaunchFailureWhenDefaultGitCannotBeResolved
  - SnapshotBuild_ReturnsNoSnapshotWhenGitCannotStart
  - CI Run 42514683492

- [x] A bare repository produces a diagnostic naming that reason

  Evidence:

  - DiscoverAsync_ReportsBareRepository
  - CI Run 42514683492
  - Limit: the test asserts the failure kind `BareRepository` and a
    non-empty diagnostic. It does not assert the wording. That the text names
    the reason ("The requested Git repository is bare and has no worktree.")
    was confirmed by reading src/Codelaxy.Git/GitRepositoryDiscovery.cs at
    `7a1b6eb`, not by a test.

- [ ] Git's own answers are used verbatim, with no path rewriting (I4)

  Evidence:

  - Partial. TryDiscoverAsync_PreservesTrailingSpaceInRepositoryRootOnUnix,
    RemoveGitLineTerminator_PreservesPathWhitespace and
    RemoveGitLineTerminator_PreservesCarriageReturnInUnixPath
    (CI Run 42514683492) show that whitespace and a trailing carriage return
    in a path survive and that only the line terminator is removed. No cited
    test covers branches or repository state, and none shows the absence of
    rewriting in general. See P1.1-CR-002.
