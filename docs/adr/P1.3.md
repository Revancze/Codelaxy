## Purpose

Decide what must be proven, whether existing proof is valid, and what the
verdict is — without knowing anything about tools.

---

## Scope

Capabilities delivered by this phase.

- [ ] Record types and their schema version

  Evidence:

  - None

- [ ] The result model of `architecture.md` §5, implemented as six distinct concepts: provider run outcome, stored evidence record, evidence evaluation against the current identity, evidence origin, requirement outcome, and verdict

  Evidence:

  - None

- [ ] Each evidence record proves exactly one requirement kind (I14) and carries the identity of the exact requirement it proves (I8)

  Evidence:

  - None

- [ ] Validity computed at evaluation time and never stored in the record

  Evidence:

  - None

- [ ] Identity binding covering requirement identity, provider identity, provider version, provider configuration, and toolchain identity as independent fields (I8)

  Evidence:

  - None

- [ ] Explainability: every decision names the facts that produced it

  Evidence:

  - None

- [ ] Conservative defaults (I2)

  Evidence:

  - None

## Gate

All items must be completed before the phase can be closed.

- [ ] No input combination produces a granted verdict from missing information

  Evidence:

  - None

- [ ] `REUSED` + `FAILED` and `EXECUTED` + `PASSED` are both representable

  Evidence:

  - None

- [ ] Changing only the adapter version invalidates reuse; changing only the tool version invalidates reuse; the two are distinguishable in the explanation

  Evidence:

  - None

- [ ] Evidence for one requirement kind never satisfies another

  Evidence:

  - None

- [ ] Two requirements of the same kind but different identities never satisfy each other

  Evidence:

  - None

- [ ] `NOT_REQUIRED` is reachable without fabricating an evidence record

  Evidence:

  - None

- [ ] An `UNKNOWN` evaluation forces fresh verification and never satisfies

  Evidence:

  - None

- [ ] The engine compiles and is tested with no provider present (I1)

  Evidence:

  - None
