Core model

Five concepts. No semantic soup.

The vocabulary is deliberately small and forms part of the architecture contract.

01

Snapshot

The exact repository state being judged.

02

Requirement

What must be proven, never how.

03

Evidence

An immutable verification record bound to identity.

04

Verdict

The decision for one exact Snapshot.

05

Provider

The component that produces fresh Evidence.

Architecture

Git is infrastructure, not a provider.

Git is authoritative for Git state

Git is invoked directly
without a shell

timestamps are never identity

uncertainty never becomes PASS

infrastructure failure
is not verification evidence

Conservative by design

Codelaxy does not guess whether stale or incomplete evidence is good enough.

Boundaries

What Codelaxy is not.

Not a build system Not a task runner Not a test framework Not a formatter Not a linter Not a dependency resolver Not a Git replacement Not a CI platform
